[#REG_EXT_HWCFG3]
==== Hardware Configuration 3 (`hwcfg3`) Register
.Fields of the `hwcfg3` register
[float="center",align="center",cols="<2,<1,<1,<1,<6",options="header"]
|===
|Field             |Bits  |R/W   |Default   |Description
|`MDCFG_FMT`       |1:0   |R     |IMP      a|Indicate the MDCFG format:

* 0x0: Format 0. The MDCFG table is implemented.
* 0x1: Format 1. No MDCFG table. `hwcfg3.MD_ENTRY_NUM` is fixed.
* 0x2: Format 2. No MDCFG table. `hwcfg3.MD_ENTRY_NUM` is programmable.
* 0x3: reserved.

|`SRCMD_FMT`        |3:2   |R     |IMP      a|Indicate the SRCMD table format:

* 0x0: Format 0 (baseline). `srcmd_en(_s_)` is implemented, and `srcmd_enh(_s_)` is implemented only when `hwcfg0.MD_NUM` > 31.
* 0x1: Exclusive Format. No SRCMD table. RRID _i_ associates exclusively with memory domain _i_, _i_ = 0 ... `hwcfg0.MD_NUM`-1.
* 0x2: MD-indexed Format. `srcmd_perm(_m_)` is implemented, and `srcmd_permh(_m_)` is implemented only when `hwcfg1.RRID_NUM` > 16.
* 0x3: reserved.

|`MD_ENTRY_NUM`     |10:4  |WARL |IMP       a|When `hwcfg3.MDCFG_FMT` = 

* 0x0: must be zero
* 0x1 or 0x2: `MD_ENTRY_NUM` indicates each memory domain has exactly (`MD_ENTRY_NUM` + 1) IOPMP entry indices

`MD_ENTRY_NUM` is locked if `hwcfg0.ENABLE` is 1.

|`XINR`             |11:11 |R    |IMP       a|Indicates whether the IOPMP treats the instruction fetch accesses as data read accesses.
All fields related to instruction fetch can be fixed to 0, or not implemented.

|`NO_X`             |12:12 |R    |IMP        |When `NO_X`=1, the IOPMP denies all instruction fetch transactions; otherwise, it depends on `entry_cfg(_i_).X`.

|`NO_W`             |13:13 |R    |IMP        |Indicate if the IOPMP always denies write accesses as if no rule matched.
|`RRID_TRANSL_EN`   |14:14 |R    |IMP        |Indicate if tagging a new RRID on the requester port is supported.
|`RRID_TRANSL_PROG` |15:15 |W1CS |IMP        |A write-1-clear bit that is sticky to 0. Indicates if the `RRID_TRANSL` field is programmable. Supported only for `RRID_TRANSL_EN`=1, otherwise, hardwired to 0.
|`RRID_TRANSL`      |31:16 |WARL |IMP        |The RRID tagged to outgoing transactions. Supported only for `RRID_TRANSL_EN`=1. It is writable only when `RRID_TRANSL_PROG`=1.

|===

[#REG_EXT_SRCMD_PERM]
==== MD _m_ RRID Permission (`srcmd_perm(_m_)` and `srcmd_permh(_m_)`) Registers

`srcmd_perm(_m_)` is read and write permissions of RRID 0 ~ 15 for MD _m_.

.Fields of the `srcmd_perm(_m_)` register
[float="center",align="center",cols="<2,<1,<1,<1,<6",options="header"]
|===
|Field  |Bits |R/W  |Default |Description
|`PERM` |31:0 |WARL |DC      |Holds two bits per RRID that give the RRID's read and write permissions for memory domain _m_. Bit 2*_s_ holds the read permission for RRID _s_, and bit 2*_s_+1 holds the write permission for RRID _s_, where _s_{le}15.
The instruction fetch permission is considered the same as the read permission.
|===

`srcmd_permh(_m_)` is read and write permissions of RRID 16 ~ 31 for MD _m_.

.Fields of the `srcmd_permh(_m_)` register
[float="center",align="center",cols="<2,<1,<1,<1,<6",options="header"]
|===
|Field   |Bits |R/W  |Default |Description
|`PERMH` |31:0 |WARL |DC      |Holds two bits per RRID that give the RRID's read and write permissions for memory domain _m_. Bit 2*(_s_-16) holds the read permission for RRID _s_, and bit 2*(_s_-16)+1 holds the write permission for RRID _s_, where _s_{ge}16. The register is implemented when `hwcfg1.RRID_NUM` > 16.
The instruction fetch permission is considered the same as the read permission.
|===
